# Ginne AI

Python automation prototype for CSV cleaning, public web research, source collection, reporting, and task tracking.

## Features
- CSV cleaning and duplicate removal
- Missing-field review
- HTTPS page fetching and multi-source reports
- JSON task queue with human-review flags

## Run
```bash
cd ~/GinneAI
python ginne_ai.py status
python ginne_ai.py demo
```

## Limitations
This is a prototype, not a production-ready autonomous AI. Research claims are not independently verified, and summaries use simple rules rather than a connected AI model.
